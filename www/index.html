Architecture & Design Overview

LocalServer is a single-process, single-threaded HTTP/1.1 server built using mio (a thin wrapper around Linux epoll). It implements the complete HTTP/1.1 specification without any external async runtime or thread pools.

Key Architectural Invariants

  • Single `epoll` Instance ([A-3]): Listeners, client sockets, and CGI child pipes are all registered in one mio::Poll.
  • One Read/Write Syscall per Event ([A-5]): The event loop executes strictly at most one read() OR one write() per client per poll wake-up, preventing client starvation.
  • Non-blocking CGI ([A-8]): Child stdio pipes are O_NONBLOCK and pumped across poll events. A slow script never blocks other clients.
  • Zero FD Leaks ([A-33]): Every socket and pipe is closed via RAII Drop immediately upon client disconnect or teardown.
  • Process Resilience ([A-20]): SIGPIPE is ignored, client handlers are wrapped in catch_unwind, and invalid HTTP syntax safely produces 400 Bad Request.
