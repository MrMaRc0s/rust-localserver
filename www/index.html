LocalServer

Single thread, single epoll, no async runtime.

If you are reading this in a browser, the static file path works: request parsing, routing, MIME detection and Content-Length are all behaving. The stylesheet and the image above are separate requests — check the network panel to confirm they were served over a reused keep-alive connection.

Try these

  • /listing/ — directory listing (autoindex)
  • /uploads/ — upload target, GET/POST/DELETE
  • /readonly/ — same files, DELETE returns 405
  • /old-page — 301 redirect back here
  • /cgi-bin/hello.py — CGI
  • /no-such-page — custom 404 page
  • /empty.html — empty page used for siege

Virtual hosts

This server and a second site share port 8080, distinguished by the Host header:

curl --resolve test.com:8080:127.0.0.1 http://test.com:8080/
