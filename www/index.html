LocalServer

Single thread, single epoll, no async runtime.

If you are reading this in a browser, the static file path works: request parsing, routing, MIME detection and Content-Length are all behaving. The stylesheet and the image above are separate requests — check the network panel to confirm they were served over a reused keep-alive connection.

Try these

  • /listing/ — directory listing (autoindex)
  • /uploads/ — upload target, GET/POST/DELETE
  • /readonly/ — same files, DELETE returns 405
  • /old-page — 301 redirect back here
  • /cgi-bin/hello.py — CGI (python)
  • /cgi-bin/info.pl — CGI (perl, same route)
  • /cgi-bin/form.py — CGI reading a POST body
  • /no-such-page — custom 404 page
  • /empty.html — empty page used for siege
  • /session — session and cookie demo

CGI

Scripts run as child processes whose pipes are registered in the same epoll as every socket, so a slow script never blocks another client. The interpreter is chosen by file extension in config.yaml, which is why python and perl scripts share one route without the server knowing either language.

Sessions

Every response carries a Set-Cookie the first time a browser arrives. /session shows the id, a visit counter and a sliding expiry — reload it and watch the counter climb, or open devtools → Application → Cookies to see the cookie itself. It is HttpOnly, so page scripts cannot read it.

Virtual hosts

This server and a second site share port 8080, distinguished by the Host header:

curl --resolve test.com:8080:127.0.0.1 http://test.com:8080/
